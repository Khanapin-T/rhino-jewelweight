# Задача
Сделай плагин для Rhino 8 (Windows) на Python 3 (CPython в Rhino 8 ScriptEditor), UI на Eto.Forms. Плагин считает вес ювелирных изделий по объёму выбранных объектов. Сначала для меня, потом будет раздаваться другим ювелирам.

# Фаза 1 — окно и расчёт
Окно:
- Команда `JewelWeight` открывает небольшое немодальное (modeless) окно поверх Rhino. Повторный запуск не создаёт второе окно, а выводит существующее на передний план.
- Левая часть:
  - сверху на всю ширину кнопка «SELECT OBJECTS»;
  - под ней сетка кнопок 3×2 без заголовков: строки — красное, жёлтое, белое; колонки — 585, 750. Текст в ячейке: «585 красное» и т.п.;
  - под сеткой на всю ширину кнопка «999»;
  - под ней на всю ширину кнопка «Серебро 925».
- Правая часть, отделена тонкой вертикальной линией: многострочное поле вывода (read-only), под ним кнопки «Копировать» и «Очистить».

Логика:
1. «SELECT OBJECTS»: выбор объектов в viewport, учитывать предвыделенные (preselect). Поддерживаемые типы: Brep / Extrusion / polysurface и Mesh (STL импортируется как mesh). Сохранить ID выбранных объектов.
2. Проверка каждого объекта: Brep — IsSolid; Mesh — IsClosed и IsManifold. Если хотя бы один объект не прошёл — расчёт полностью блокируется: в вывод написать, сколько объектов и что с ними (открытый, non-manifold, неподдерживаемый тип), и выделить проблемные объекты в Rhino.
3. Объём через `VolumeMassProperties.Compute`, не через команду Volume. Суммировать по всем объектам. Если объём меша отрицательный (вывернутые нормали) — взять модуль и добавить предупреждение.
4. Перевести объём в мм³ с учётом единиц документа (`ModelUnitSystem`, `RhinoMath.UnitScale`).
5. При клике на кнопку металла заново пересчитать объём по сохранённым ID (объект могли изменить или удалить; про удалённые сообщить). Вес = объём_мм³ × плотность_г/см³ / 1000, округление до 0.01 г.
6. Строка вывода: «585 красное: 4.37 г (2 объекта)». Новые записи сверху.
7. Если выбрано больше одного объекта — один раз добавить предупреждение: пересекающиеся тела считаются дважды, камни и вставки выделять не нужно.
8. «Копировать» копирует последнюю запись в буфер обмена, «Очистить» очищает вывод.

Плотности по умолчанию (г/см³) — середина диапазона между вариантами сплавов из ГОСТ 30649-99 и типовыми международными значениями, чтобы погрешность была минимальной в обе стороны. Вынеси в один конфиг. В «Настройках» под каждым стандартным металлом мелким текстом: «среднее значение, уточните для своего сплава».

585 жёлтое — 13.49
585 белое — 13.76
750 красное — 15.07

Серебро 925 — 10.36

# Фаза 2 — настройки и свои сплавы
- В окне две вкладки: «Расчёт» и «Настройки».
- «Настройки»: список всех металлов. У стандартных название и проба только для чтения, редактируется только плотность (числовое поле, допустимо 5–25 г/см³, принимать точку и запятую). Кнопка «Сбросить стандартные». Формулу пользователю не показывать.
- «Добавить свой сплав»: поля Название, Проба (необязательно), Плотность. Свои сплавы можно редактировать и удалять.
- На вкладке «Расчёт» под кнопкой «Серебро 925» мелкий заголовок «Свой металл:», под ним кнопки своих сплавов на всю ширину, по одной в строке, стопкой вниз. Если их много — эта область прокручивается, окно не растёт бесконечно.
- Хранение настроек и истории: JSON в %APPDATA%\JewelWeight\ или Rhino PersistentSettings — выбери и объясни почему. Обновление плагина не должно стирать настройки.
- История вывода сохраняется между запусками, максимум 50 последних записей. «Очистить» очищает и сохранённую историю.
