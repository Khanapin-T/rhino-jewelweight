# JewelWeight

Плагин для Rhino 8 (Windows): считает вес ювелирного изделия по объёму выбранных тел.

- Сплавы: 585 и 750 (красное, жёлтое, белое), 999, серебро 925. Плотности по умолчанию — среднее между ГОСТ 30649-99 и типовыми международными значениями.
- Объекты: полиповерхности, extrusion, меши (в том числе импортированные STL).
- Перед расчётом каждый объект проверяется: он должен быть замкнутым и manifold. Проблемные объекты выделяются в Rhino.
- Единицы документа учитываются автоматически.

- Свои сплавы и уточнённые плотности хранятся в `%APPDATA%\JewelWeight\settings.json`. Обновление плагина их не стирает; файл можно скопировать на другой компьютер.

## Установка (только Rhino 8)
1. Скачайте `JewelWeight-<версия>.zip` в разделе **Releases** этого репозитория и распакуйте архив целиком.
2. В Rhino 8 введите `_ScriptEditor` → File → Open → `install.py` из распакованной папки → Run (F5).
3. Введите команду `JewelWeight`.

Обновление: распакуйте новую версию и снова запустите `install.py` — свои сплавы и плотности сохранятся. Удаление: запустите `uninstall.py`.

Программа ставится в `%APPDATA%\JewelWeight\app`, команда `JewelWeight` — это псевдоним (alias) Rhino.

Выпуск новой версии описан в [docs/BUILD.md](docs/BUILD.md).

## Разработка
- `src/commands/JewelWeight.py` — команда `JewelWeight`.
- `src/lib/jewelweight/` — библиотека: логика отдельно от интерфейса.
- Запуск без сборки: в Rhino 8 выполнить `_ScriptEditor`, открыть `src/commands/JewelWeight.py`, нажать Run.
- Тесты логики (обычный Python 3.9+, без Rhino):

  ```
  python -X utf8 -m unittest discover -s tests -v
  ```
