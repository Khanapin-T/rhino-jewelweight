## Key decisions
- `MIN_RHINO_VERSION = (8, 0, 0)`, то есть любой Rhino 8. При Publish выбирать самый ранний Build Target 8.x.
- Хранятся только изменённые плотности стандартных металлов, чтобы новые значения по умолчанию доходили до пользователей.
- Выбор: `rs.GetObjects`, фильтр 8|16|32|SubD|extrusion (сфера — односторонний solid; SubD → «неподдерживаемый»).
- Удалённые объекты: сообщение плюс расчёт по оставшимся. Предупреждения по объектам — один раз на выбор.
- «Копировать» берёт последнюю строку с весом; на кнопке ненадолго появляется «Скопировано ✓».

## Gotchas
- Не проверено в Rhino: Drawable-кнопки, автопрокрутка Scrollable, перенос строк в карточках, MessageBox YesNo, Mesh.Check.
- Модули кешируются: закрыть окно → снова Run, чтобы подхватить код.
