## Key decisions
- `MIN_RHINO_VERSION = (8, 0, 0)`, то есть любой Rhino 8: у пользователя три ПК с разными 8.x. При Publish выбирать самый низкий Build Target 8.x. Поднять минимум, только если старый SR реально ломает плагин.
- Выбор объектов через `rs.GetObjects` с фильтром 8|16|32|SubD|extrusion: поверхности нужны, потому что сфера — односторонний solid; SubD допускается к выбору только ради сообщения «неподдерживаемый тип».
- Extrusion → `ToBrep(False)`. Если brep non-manifold, сообщается только non-manifold, без «открытого».
- Удалённые объекты при клике на металл: сообщение плюс расчёт по оставшимся; если удалены все — ошибка.
- Предупреждение о пересечениях выводится один раз на выбор; про вывернутые нормали — один раз на объект в выборе.
- «Копировать» копирует последнюю строку результата (вес), а не предупреждение.
- Единицы None и CustomUnits блокируют расчёт.
